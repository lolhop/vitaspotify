VitaSpotify — create auth.json
================================

You need Spotify Premium and the Spotify app on your phone (same Wi-Fi as this PC).

WINDOWS
  Open the "windows" folder → double-click "Get VitaSpotify Login.bat"
  (Do not run the .exe by itself.)

MAC
  Open the "mac" folder → double-click "Get VitaSpotify Login.command"

LINUX
  Open the "linux" folder → run ./get-vitaspotify-login.sh

In Spotify: play a song → Connect to a device → pick "CSpot player".
When you see SUCCESS, find "vitaspotify auth.json" on your Desktop.

COPY TO PS VITA
  VitaShell (USB or FTP) → ux0:data/vitaspotify/auth.json
  Then in VitaSpotify: Log in (auth.json)

Keep auth.json private. Do not share it online.
